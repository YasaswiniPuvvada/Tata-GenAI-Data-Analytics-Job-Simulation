# Tata GenAI Powered Data Analytics Job Simulation

## 📊 Project Overview

This repository contains my work from the **Tata GenAI Powered Data Analytics Job Simulation – Forage**.

The project focused on a practical **customer delinquency and collections strategy** case, covering data analysis, predictive modeling concepts, business recommendations, and an AI-powered collections solution.

## 🎯 Project Objectives

- Analyze customer delinquency data and identify data-quality issues.
- Explore customer payment behavior and financial indicators.
- Develop a conceptual approach for predicting delinquency risk.
- Translate analytical findings into business recommendations.
- Design a high-level AI-powered collections system.
- Apply Responsible AI and human-in-the-loop principles.

## 🔍 Project Work

### 1. Exploratory Data Analysis
- Identified missing values, duplicates, inconsistencies, and potential anomalies.
- Analyzed delinquent vs. non-delinquent customers.
- Examined Credit Score, Credit Utilization, Debt-to-Income Ratio, Missed Payments, and payment behavior.
- Identified initial indicators requiring further investigation.

### 2. Predictive Model Plan
Proposed a conceptual **Logistic Regression** approach for delinquency risk classification.

**Key areas:** Feature selection, data preparation, train/test split, risk classification, and model evaluation using Precision, Recall, F1-Score, ROC-AUC, and Confusion Matrix.

> This was a conceptual exercise and did not require training a working ML model.

### 3. Business Recommendations
Translated analytical findings into actionable recommendations focused on:

- Recent payment behavior
- Credit utilization
- Debt-to-income ratio
- Early risk identification
- Targeted customer outreach

Recommendations were structured using the **SMART framework**.

### 4. AI-Powered Collections Strategy
